# Finished My First freeCodeCamp Certification

**Date:** March 17, 2026
**Tags:** freecodecamp, learning, front-end, milestone

---

Wrapped up the Responsive Web Design certification from freeCodeCamp today. Feels good to have it done and honestly it went better than I expected.

## How It Went

I took my time with it — spread across a few months, fitting it in around everything else. At first I was moving slow, getting familiar with the structure of the course and finding my rhythm. But somewhere along the way it just clicked and I locked in. Once that happened the lessons flew by.

If you're thinking about starting it, I'd call it genuinely beginner friendly. freeCodeCamp does a solid job of introducing concepts gradually and letting you practice as you go. You're not just reading — you're writing code the whole way through, which makes a big difference.

## The Projects

The projects were where it got real. Following along with lessons is one thing, but sitting down with a blank file and building something from scratch is a different challenge entirely. That's where I spent the most time and ran into the most friction.

The one that gave me the most trouble was the **CSS Build a Book Inventory App**. Nothing catastrophic, just a lot of back and forth getting things to behave the way I wanted. Good problem-solving practice though — the kind of thing that actually sticks.

I got through all five projects and passed, but I'll be honest — I want to go back and redo some of them. Now that I have a better feel for HTML and CSS I think I could do them a lot cleaner. That's a future task.

## What's Next

Finishing this cert confirmed something for me — I want to go deeper into front-end. The way a good layout comes together, the way CSS can go from frustrating to satisfying when it finally works, the connection between design and code — I'm into it.

Next up is the JavaScript Algorithms and Data Structures cert. A different beast, but I'm ready for it.

Cert is verified [here](https://www.freecodecamp.org/certification/jjones26/responsive-web-design) if you want to check it out.
