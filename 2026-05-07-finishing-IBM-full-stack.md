# Wrapping Up the IBM Full Stack Software Developer Program

I’m finally down to the last stretch of the IBM Full Stack Software Developer program through Coursera. Right now I’m wrapping up the capstone project, which honestly feels pretty rewarding after all the hours that went into this program.

It’s been a lot of late nights, extra study sessions after work, and figuring things out through trial and error, but I can genuinely say it’s been worth it. I learned a ton throughout the program and got way more hands-on experience than I expected going in. The labs and practice projects were probably my favorite part because they forced me to actually build things instead of just watching videos and taking notes.

Over the course of the program I worked with front end and back end technologies, Git/GitHub workflows, databases, APIs, cloud concepts, and deployment practices. It definitely helped make software development feel less intimidating and a lot more practical.

Once I finish the capstone, I still have the final assessment to tackle, and then I’ll officially be done with the certification.

After that, the plan is to keep the momentum going with personal projects. First up is a full stack CRUD app that doubles as a habit tracker themed around Skyrim skill trees. I’ve wanted to build something that mixes gaming-inspired design with actual functionality for a while, so that’ll be my next big focus.

At the same time, I’ll be starting the process of applying to software developer, software engineer, and full stack developer roles while continuing to build projects and work on interview prep. Still a lot to learn, but definitely excited for what’s next.
